# Security policy / Безопасность

Do not post real router backups, SSH keys, access tokens, DHCP leases, domain history or unredacted screenshots in issues. Reports should use synthetic data and reproduction steps. Remove credentials before submitting patches. This project has not undergone an independent security audit; no warranty or blanket security guarantee is provided.

Не публикуйте реальные резервные копии роутера, SSH-ключи, токены, DHCP-аренды, историю доменов и необезличенные скриншоты. Для воспроизведения используйте вымышленные данные. Независимый аудит безопасности не проводился; абсолютная безопасность не обещается.

GitHub Actions in this repository only performs local static checks with read-only repository permissions. There are no upload, deployment or credential-generating workflows.
